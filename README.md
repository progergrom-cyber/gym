# Тренер для зала 🏋️

PWA-приложение для небольшой компании друзей: составляет план тренировки
на день из тренажёров нашего клуба, ведёт дневник подходов и подсказывает вес.

**Страницы приложения:**
- **Тренировка** — выбор времени и типа, план, отметка подходов, таймер отдыха.
- **Прогресс** — история тренировок, замеры тела, график веса.
- **Профиль** — рост, цель, частота, травмы; общий каталог тренажёров.

**Файлы:**

| Файл | Что делает |
|---|---|
| `app.py` | сервер (Flask): вход, профиль, план, дневник |
| `planner.py` | генератор плана |
| `progression.py` | подсказка веса на следующий раз |
| `catalog_seed.py` | стартовый каталог тренажёров |
| `static/photos/` | фото тренажёров (создаётся само, в GitHub не попадает) |
| `db.py` | база данных SQLite (файл `gym.db` создаётся сам) |
| `manage.py` | инвайт-коды и смена пароля из консоли |
| `static/` | страницы, стили, скрипты, иконки, service worker |
| `tests/` | тесты генератора |

## 1. Загрузка кода на GitHub (один раз)

1. Зарегистрируйтесь на <https://github.com> (кнопка **Sign up**).
2. Справа вверху нажмите **+** → **New repository**.
   - *Repository name*: `gym`
   - Выберите **Public** (в коде нет паролей и личных данных — база и
     секретный ключ в GitHub не попадают).
   - Галочки *Add a README* и прочие **не ставьте**.
   - Нажмите **Create repository**.
3. На компьютере откройте папку `Gym`, нажмите в пустом месте правой кнопкой
   с зажатым **Shift** → **Открыть окно PowerShell здесь** (или «Открыть в Терминале»).
4. Вставьте по очереди (вместо `ВАШ_ЛОГИН_GITHUB` — ваш логин на GitHub):

   ```
   git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/gym.git
   git push -u origin main
   ```

   Откроется окно браузера «Sign in to GitHub» → нажмите **Sign in with your browser**
   → **Authorize**. В PowerShell появятся строки вида `Writing objects: 100%` —
   код загружен. Обновите страницу репозитория на GitHub — там появятся файлы.

## 2. Регистрация на PythonAnywhere

1. Откройте <https://www.pythonanywhere.com> → **Pricing & signup** →
   **Create a Beginner account** (бесплатно).
2. Логин, который вы выберете, станет адресом сайта:
   `https://ЛОГИН.pythonanywhere.com`. Дальше везде вместо `ЛОГИН` пишите его.
3. Подтвердите почту по ссылке из письма.

## 3. Скачивание кода на PythonAnywhere

1. Вверху нажмите **Consoles** → в разделе *Start a new console* нажмите **Bash**.
   Откроется чёрное окно с командной строкой `$`.
2. Вставьте (правая кнопка мыши → Paste или Ctrl+Shift+V) и нажмите Enter:

   ```
   git clone https://github.com/ВАШ_ЛОГИН_GITHUB/gym.git
   ```

   Должно появиться `Cloning into 'gym'... done.`
3. Перейдите в папку и установите зависимости:

   ```
   cd ~/gym
   pip3.13 install --user -r requirements.txt
   ```

   Скорее всего, будет написано `Requirement already satisfied` — Flask там уже есть.
   > ⚠️ Цифра `3.13` — версия Python. Используйте ту же, что выберете на шаге 4
   > (например, `pip3.12` и `python3.12`, если выбрали 3.12).
4. Проверьте, что всё работает, — запустите тесты:

   ```
   python3.13 -m unittest
   ```

   В конце должно быть `OK`.
5. Создайте инвайт-коды для себя и друзей (5 штук):

   ```
   python3.13 manage.py invite 5
   ```

   Появятся строки вида `Инвайт-код: K7QM-3XRA`. Скопируйте их — каждый код
   работает один раз. Позже можно посмотреть все коды: `python3.13 manage.py invites`.

## 4. Создание веб-приложения

1. Вверху нажмите **Web** → **Add a new web app** → **Next**.
2. Выберите **Manual configuration** (не «Flask»!) → выберите версию Python
   (самую новую из списка, например **Python 3.13**) → **Next**.
3. Откроется страница настроек приложения. Пролистайте до раздела **Code**:
   - **Source code**: нажмите на путь, впишите `/home/ЛОГИН/gym` и нажмите ✓.
   - **Working directory**: так же впишите `/home/ЛОГИН/gym` и ✓.
   - **WSGI configuration file**: нажмите на ссылку
     `/var/www/ЛОГИН_pythonanywhere_com_wsgi.py`. Откроется редактор.
     Выделите всё (Ctrl+A), удалите и вставьте:

     ```python
     import sys

     path = '/home/ЛОГИН/gym'
     if path not in sys.path:
         sys.path.insert(0, path)

     from app import app as application
     ```

     Замените `ЛОГИН` на ваш логин PythonAnywhere, нажмите **Save**
     (справа вверху) и вернитесь на вкладку **Web**.
4. Раздел **Static files** — нажмите *Enter URL* и впишите `/static/`,
   затем *Enter path* — `/home/ЛОГИН/gym/static/`. Нажимайте ✓ после каждого поля.
5. Раздел **Security** — переключите **Force HTTPS** в положение *Enabled*.
   (HTTPS на адресе `*.pythonanywhere.com` уже есть бесплатно; без него
   приложение не установится на телефон.)
6. Вверху страницы нажмите зелёную кнопку **Reload ЛОГИН.pythonanywhere.com**.
7. Откройте `https://ЛОГИН.pythonanywhere.com` — должна появиться страница входа.
   Нажмите **Регистрация**, введите логин, пароль и один из инвайт-кодов.

**Если что-то не работает:** на вкладке **Web**, раздел *Log files*, откройте
**Error log** — последние строки внизу покажут ошибку. Пришлите их мне.

## 5. Как обновлять приложение после изменений

1. Когда код на компьютере поменялся, в PowerShell в папке `Gym`:

   ```
   git add .
   git commit -m "Что поменяли"
   git push
   ```

2. На PythonAnywhere: **Consoles** → откройте существующую Bash-консоль
   (или новую **Bash**) и выполните:

   ```
   cd ~/gym
   git pull
   ```

3. Вкладка **Web** → зелёная кнопка **Reload**.

Данные пользователей (`gym.db`) и фото тренажёров (`static/photos/`)
при обновлении **не трогаются**.
Иногда делайте резервную копию: вкладка **Files** → папка `gym` → у файла
`gym.db` нажмите значок скачивания. Фото лежат в `gym/static/photos/`.

## 6. Продление сайта каждый месяц

Бесплатный сайт работает 1 месяц, потом его нужно продлить (это бесплатно):

1. Зайдите на <https://www.pythonanywhere.com> → вкладка **Web**.
2. Нажмите кнопку **Run until 1 month from today** (раздел *Best before date*).

PythonAnywhere присылает письмо-напоминание за неделю до отключения.
Если пропустили — сайт выключится, но данные не пропадут: нажмите ту же
кнопку и **Reload**.

## 7. Установка на Android (для друзей)

1. Откройте **Chrome** и перейдите на `https://ЛОГИН.pythonanywhere.com`.
2. Нажмите **Регистрация**, введите логин, пароль и инвайт-код, который
   вам дали. Нажмите **Зарегистрироваться**.
3. Нажмите **⋮** (три точки справа вверху) → **Добавить на главный экран**
   (или **Установить приложение**) → **Установить**.
4. На главном экране появится иконка **«Тренер»** с гантелью — приложение
   открывается в отдельном окне, как обычное.
5. Совет: составляйте план **дома или по дороге** (нужен интернет). В зале
   план откроется и без связи, подходы сохранятся в телефоне и отправятся
   на сервер, когда интернет появится.

## Полезные команды (Bash-консоль PythonAnywhere, в папке `~/gym`)

| Команда | Что делает |
|---|---|
| `python3.13 manage.py invite` | новый инвайт-код |
| `python3.13 manage.py invites` | список кодов и кто их использовал |
| `python3.13 manage.py users` | список пользователей |
| `python3.13 manage.py password ЛОГИН_ДРУГА` | задать новый пароль, если друг забыл |
| `python3.13 -m unittest` | запустить тесты |

Откройте в браузере <http://127.0.0.1:5000>. Инвайт-код для локальной проверки:
`python manage.py invite`.
